# Prism Bastion / 棱镜堡垒

一个使用 React、TypeScript、esbuild 与 Canvas 2D 构建的俯视角模块化塔防原型。视觉只使用白底、亮色和简单几何图形。

## 运行

```bash
npm install
npm run dev
```

打开 `http://localhost:4173`。生产构建使用：

```bash
npm run build
```

## 核心规则

- 点击战场中的虚线节点建造炮塔，每座消耗 80 晶片。
- 新炮塔的槽位为空，因此默认不会攻击。
- 点击炮塔会在地图上打开半透明的 ARC WORKSHOP；按模块类型切换页面，选择模块后点击槽位安装，也可以拖拽调整顺序。点击地图空处或关闭按钮会收起工作台。
- 槽位从左向右执行。修正与逻辑模块优先影响右侧的下一枚弹射物；若序列末端仍有未完成的法术块，则会回绕到槽位 1 再读取一圈。
- 每一轮完整施法会一次性检查总能量，并受炮塔自身冷却时间限制。
- 炮塔的能量上限、回复速度、基础冷却、槽位数量与射程由固定预算的随机构型系统共同生成；内部点数不会占用工作台界面。
- 每座塔可以独立选择血量、核心距离、炮塔距离或局部密度优先级，并在波次间消耗晶片升级。

每座新塔从 `90` 能量上限、`11/秒` 回复、`1.15 秒`冷却、`3` 个槽位与 `175` 射程起步，再随机花费 `12` 点内部构型预算。容量、回复、冷却与射程强化每级消耗 1 点，每个额外槽位消耗 3 点，因此高槽位或远射程炮塔必然会在其他属性上作出牺牲。十万次种子采样下，平均新塔为 `135.35` 能量、`14.87/秒` 回复、`1.02 秒`冷却、`4.02` 槽和 `201.67` 射程。

例如 `回响 → 分叉 → 冷凝 → 脉冲` 会延迟重复一次三发减速脉冲；而 `脉冲 → 过载` 会先释放普通脉冲，再从末端回绕到槽位 1，额外释放一枚过载脉冲。回绕产生的法术照常计入本轮总能耗。

当前内置 22 个模块。玩法包括链式电弧、飞行脉冲、回旋穿透、弹跃改道、持续腐蚀、静态载荷、尾迹修正与嵌套触发；模块库可按 `P / S / M / T / L` 类型筛选。

模块分为普通、优秀、稀有、传奇四级。它们不是同强度换皮：高级模块拥有更高的条件效率、作用目标数或组合乘区；对应的基础抽取权重为 `100 / 40 / 10 / 2`。正式模式连续两轮未出现稀有或传奇时，下一轮会触发同类别保底。

关卡选择页提供三张拥有独立路线、节点、波次和敌人倍率的地图。正式模式从有限模块库存开始，每波结束进行三轮四选一；每轮固定包含 1–2 个弹射物和 1–2 个修正/尾迹模块，并提高未拥有模块的出现权重。模块库可按类型或 `ALL` 浏览；已经全部装配的模块仍会显示，但标记为“已用完”并排在可用模块之后，拆下后会自动回到可用区。创造模式无限使用全部模块，可配置下一波的敌人构成、生命与速度倍率，也能即时投放单个敌人。

开始游戏前可以选择休闲、轻松、正常、困难或极限难度。难度只乘算敌人生命与速度、我方最终伤害和晶片经济，不添加新敌人能力或改变波次结构；创造模式的自定义生命、速度倍率会与难度倍率相乘。

战场使用独立的 emissive 缓冲与 WebGL 后处理：炮口、弹体、命中、闪电和静态装置会生成彩色柔光，同时保留清晰的白热核心。在白底主题中使用有上限的色彩侵染，避免传统 additive 泛光被白色背景吞掉。

“棱镜领主”拥有大范围六边形力场；为便于组合测试，白棱镜区的第一波和最终波次都会生成一只。弹体会先与护盾边界碰撞，伤害优先消耗护盾；破盾后的溢出伤害才会命中本体。基础护盾为 240，破裂会进入 9 秒回复债务，随后以 4/秒从零重新充能。力场存续期间，WebGL 会一直在六边形表面运行交错折射波和移动亮纹；受击只会增强振幅并追加向外扩散的冲击波。破盾与重启另有碎裂扩散和聚合特效。Boss 出现时，战场顶部会显示独立的护盾与生命状态条。

`S` 类静态投射物不能从炮塔射出，也不能作为顶层施法。它必须被放进触发器的载荷中，并直接在碰撞点、计时点或其他触发位置生成；非法直放会在程序面板中得到诊断。

推荐尝试：

- `弹跃 → 巨化 → 刃片`：大型刃片会在多个目标间改道切割。
- `节能 → 四连 → 脉冲`：用较低能耗换取四发低伤脉冲。
- `腐蚀 → 分叉 → 弧链`：三枚电核分别感染目标并向敌群传导。
- `巨化 → 新星`：获得更大的弹体和约 90 范围的爆炸。
- `命中触发 → 脉冲 → 过载 → 新星`：脉冲命中后才在目标位置生成强化新星。
- `命中触发 → 脉冲 → 毒雾`：脉冲命中处原地生成持续腐蚀区域。
- `命中触发 → 脉冲 → 接近触发 → 感应雷 → 新星`：脉冲命中处生成地雷，敌人接近后同时引爆地雷与新星载荷。
- `脉冲 → 新星 → 命中触发`：先正常释放脉冲和新星，末端触发器回绕后再组成一组“脉冲命中新星”法术块。

## 架构

- `src/game/engine.ts`：战斗状态、模块运行时钩子与更新循环
- `src/modules/`：单文件模块定义、注册表和顺序编译器
- `src/effects/`：统一生命周期效果引擎、Canvas 绘制器与效果工厂
- `src/game/renderer.ts`：Canvas 战场绘制与分层效果合成
- `src/game/config.ts`：地图、波次和敌人数据
- `src/game/tower-generation.ts`：固定预算的随机炮塔属性生成器
- `src/ui/App.tsx`：React 工作台、拖放交互和状态面板

添加模块和编写效果的完整约定见 [docs/architecture.md](docs/architecture.md)，完整模块说明见 [docs/modules.md](docs/modules.md)。完整估值公式、稀有度预算、逐波 EHP 与经济计算见 [docs/balance.md](docs/balance.md)。
