# Project Skills

These provider-neutral skills capture repeatable Prism Bastion workflows for coding agents and human contributors. Each skill is a directory containing a `SKILL.md` entry point and, when useful, focused reference files.

| Skill | Use it to... |
| --- | --- |
| [Thought Index authoring](thought-index-authoring/SKILL.md) | Design, review, or implement a focused Ponder-style module demonstration |

Open the matching `SKILL.md` before starting the task and load only the references it routes you to.
